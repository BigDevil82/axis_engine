# axis_engine

本目录负责 CAD 几何解析中的核心算法，目标是把原始双线构件表示转换为更适合后续图建模和推理的几何表达。

## 主要职责

- 墙体中轴线提取
- 线网校准与连接修复
- 平面矩形分解
- CAD 布局处理的几何基础能力

## 主要文件

- `cad_processor.py`: 组合 CAD 处理流程
- `wall_centerline.py`: 墙体中轴线提取
- `line_network_calibrator.py`: 线网对齐与拓扑修复
- `rect_decomposer.py`: 矩形分解

## 边界建议

- 这里应尽量保持为“可复用几何引擎”
- 不建议掺入训练逻辑、论文分析脚本、外部软件桥接代码
- 新增功能若属于几何处理基础能力，应优先放在这里
