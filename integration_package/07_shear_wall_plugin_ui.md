# 剪力墙智能设计插件 UI 规划

本页基于实际交互流程重新规划 CAD 插件选项卡。原则是：插件按钮只承载业务流程动作，CAD 已有的画线、删除、延长、修剪等基础编辑能力不重复做一套。

## 交互主线

```text
框选一个平面图
  -> 设置墙体/门窗/轴线图层
  -> 仅显示已选图层，人工确认输入
  -> 提取骨架
  -> 查看墙轴线、门窗嵌入线、房间分区、孤立点标记
  -> 工程师用 CAD 原生命令修正骨架结果图层
  -> 提交骨架修正，后端重新检查分区和孤立点
  -> 确认骨架
  -> 生成结构布置
  -> 查看剪力墙、梁、未闭合提示
  -> 工程师用 CAD 原生命令修正结构结果图层
  -> 提交结构修正，后端检查搭接和闭合
  -> 生成 YDB
  -> 下载或写回结果
```

## 选项卡按钮

### 1. 对象范围

用于限定当前操作对象。因为一个 DWG 中可能有多个平面图，所有后续操作都只作用于当前框选范围。

| 按钮 | 作用 |
| --- | --- |
| 框选平面图 | 在 CAD 中框选一个平面图作为本次任务范围 |
| 清除范围 | 清除当前选择范围，重新选择 |
| 查看范围 | 高亮当前范围边界，避免误操作其他平面图 |

### 2. 图层设置

用于配置算法输入来源。

| 按钮 | 作用 |
| --- | --- |
| 设置图层 | 打开小窗，分别为墙体、门窗、轴线设置多选图层 |
| 仅显示输入图层 | 只显示已选墙体、门窗、轴线图层，便于确认和清理 |
| 恢复全部图层 | 恢复 CAD 原图层显示状态 |

图层设置小窗应包含：

| 字段 | 控件 |
| --- | --- |
| 墙体图层 | 多选下拉框 |
| 门窗图层 | 多选下拉框 |
| 轴线图层 | 多选下拉框 |
| 操作 | 确定、取消、仅显示选择图层 |

### 3. 骨架流程

用于从原始图元生成并迭代校准建筑骨架。

| 按钮 | 作用 |
| --- | --- |
| 提取骨架 | 前端读取范围内已选图层图元，调用 `extract_skeleton`，并绘制响应中的 `isolated_points` |
| 提交骨架修正 | 读取工程师修改后的墙轴线和门窗嵌入线图层，调用 `normalize_skeleton`，并用新 `isolated_points` 覆盖旧标记 |
| 确认骨架 | 锁定当前骨架，作为结构布置输入 |

骨架结果图层建议：

- 墙体轴线。
- 门窗嵌入线。
- 房间分区。
- 孤立点诊断标记：每个 `isolated_points` 坐标一个标记，用于定位悬垂端点；不作为可回传的骨架对象。

### 4. 结构流程

用于生成结构布置、提交修正和生成模型文件。

| 按钮 | 作用 |
| --- | --- |
| 生成结构 | 将确认后的骨架提交后端，调用 `design_structure` |
| 提交结构修正 | 读取工程师修改后的剪力墙和梁图层，调用 `normalize_structure` |
| 生成 YDB | 当结构结果无明显未闭合问题时，调用建模接口生成 YJK 模型文件 |

结构结果图层建议：

- 剪力墙。
- 梁。
- 结构诊断标记。
- 楼板分区。

### 5. 显示检查

用于控制结果显示和定位问题。

| 按钮 | 作用 |
| --- | --- |
| 显示骨架 | 开关墙轴线和门窗嵌入线结果图层 |
| 显示孤立点 | 开关 `isolated_points` 诊断标记 |
| 显示分区 | 开关房间/楼板分区填色 |
| 显示结构 | 开关剪力墙和梁结果图层 |
| 定位问题 | 依次跳转到 `isolated_points` 及后端返回的未闭合、未搭接、悬垂构件等问题位置 |

### 6. 输出信息

用于输出最终成果和查看插件状态。

| 按钮 | 作用 |
| --- | --- |
| 下载 YDB | 下载后端生成的 YDB 文件 |
| 写回 CAD | 将当前结果写入约定 CAD 图层 |
| 导出报告 | 导出构件数量、诊断问题、接口调用结果 |
| 插件信息 | 显示版本、服务地址、接口连通状态 |

## 不建议放入插件 ribbon 的按钮

以下能力由 CAD 原生命令或通用编辑工具完成，不建议在插件里重复做：

- 添加轴线。
- 删除轴线。
- 延长相交。
- 修剪毛刺。
- 添加洞口。
- 删除洞口。
- 添加剪力墙。
- 删除剪力墙。
- 添加梁。
- 删除梁。
- 修改梁类型。

插件只需要约定这些对象所在的结果图层和属性表达方式。工程师修改后点击“提交骨架修正”或“提交结构修正”，由后端重新检查。
