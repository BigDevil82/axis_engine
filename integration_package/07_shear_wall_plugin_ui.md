# 剪力墙智能设计插件 UI 规划

本页用于说明 CAD 插件选项卡应包含哪些按钮，以及这些按钮如何服务完整交互流程。

## 选项卡分组

### 1. 输入设置

用于从当前 CAD 图中获取业务输入。

| 按钮 | 作用 |
| --- | --- |
| 选择墙体图层 | 指定墙体原始图元来源 |
| 选择门窗图层 | 指定门窗、阳台等洞口图元来源 |
| 选择轴网图层 | 指定轴网图层 |
| 读取图元 | 从已选图层读取基础图元并统计数量 |

### 2. 骨架提取

用于生成和检查建筑轴线骨架。

| 按钮 | 作用 |
| --- | --- |
| 提取骨架 | 调用 `extract_skeleton` |
| 校准骨架 | 调用 `normalize_skeleton` |
| 生成房间分区 | 根据骨架重新计算 `slab_regions` |
| 查看诊断 | 显示墙轴线、洞口、楼板分区数量和异常信息 |

### 3. 骨架编辑

用于修正自动提取错误。

| 按钮 | 作用 |
| --- | --- |
| 添加轴线 | 手动补充墙体轴线 |
| 删除轴线 | 删除误识别墙轴线 |
| 延长相交 | 延长端点，使线段搭接 |
| 修剪毛刺 | 删除短小悬垂线段 |
| 添加洞口 | 手动补充门窗嵌入线 |
| 删除洞口 | 删除误识别门窗嵌入线 |

### 4. 结构生成

用于从确认后的骨架生成初步结构方案。

| 按钮 | 作用 |
| --- | --- |
| 生成剪力墙 | 根据墙轴线生成剪力墙 |
| 生成梁 | 生成边梁、阳台梁、连梁、板划分梁 |
| 校准结构 | 调用 `normalize_structure` |
| 重新分区 | 根据结构构件重新生成楼板分区 |

### 5. 结构编辑

用于工程师修正结构设计结果。

| 按钮 | 作用 |
| --- | --- |
| 添加剪力墙 | 手动补充剪力墙 |
| 删除剪力墙 | 删除不合理剪力墙 |
| 添加梁 | 手动补充梁 |
| 删除梁 | 删除不合理梁 |
| 延长梁 | 延长梁端确保搭接 |
| 修改梁类型 | 在边梁、阳台梁、连梁、板划分梁之间切换 |

### 6. 导出信息

用于保存和输出。

| 按钮 | 作用 |
| --- | --- |
| 保存骨架 | 将当前骨架写回 CAD 或保存到插件状态 |
| 保存结构 | 将当前剪力墙和梁写回 CAD 或保存到插件状态 |
| 写回 CAD | 写入指定结果图层 |
| 导出报告 | 导出数量统计和诊断信息 |
| 插件信息 | 显示版本、接口状态和帮助信息 |
