# 真实案例演示模板

该文档用于给软件公司展示“自动结果 + 人工修正”的真实工作流。每个案例建议使用一张典型住宅平面图。

## 案例文件结构

```text
sample_cases/
  case_01_typical_apartment/
    01_original_plan.dwg
    02_selected_layers.png
    03_auto_skeleton.png
    04_edited_skeleton.png
    05_auto_structure.png
    06_edited_structure.png
    notes.md
```

## 每个案例应说明

### 1. 原始图纸

- 图纸用途：住宅标准层、底商、地下室等。
- 关键图层：墙体、门窗、轴网。
- 图纸特点：块嵌套、门窗样式复杂、阳台多、非矩形区域等。

### 2. 自动骨架结果

展示：

- 建筑底图。
- 墙轴线。
- 门窗嵌入线。
- 楼板分区。

记录：

- 墙轴线数量。
- 门窗嵌入线数量。
- 楼板分区数量。
- 需要人工修正的问题。

### 3. 人工修正骨架

至少展示一种人工操作：

- 补一条墙轴线。
- 修正一条门窗嵌入线。
- 删除一条误识别线。

说明修正后楼板分区如何变化。

### 4. 自动结构结果

展示：

- 剪力墙。
- 边界梁。
- 阳台梁。
- 连梁。
- 板划分梁。
- 楼板分区。

记录：

- 剪力墙数量。
- 各类梁数量。
- 哪些位置需要工程师判断。

### 5. 人工修正结构结果

至少展示一种人工操作：

- 缩短一段剪力墙。
- 补一条梁。
- 删除一条不合理板划分梁。
- 修改梁类型。

## 首批建议案例

| 案例 | 目的 |
| --- | --- |
| 典型规则住宅 | 展示主流程和较好的自动效果 |
| 阳台较多住宅 | 展示阳台过梁和外围边界梁检查 |
| 门窗图层复杂图纸 | 展示骨架人工修正的重要性 |
| 大板区域较多图纸 | 展示板划分梁和楼板分区反馈 |

## 演示叙事建议

给软件公司展示时不要只放最终结果，建议按下面顺序播放：

```text
原始图 -> 选择图层 -> 自动骨架 -> 骨架修正 -> 自动结构 -> 结构修正 -> 写回 CAD
```

他们需要理解的重点不是某一张结果图，而是产品必须支持“算法生成”和“工程师编辑”之间来回切换。
