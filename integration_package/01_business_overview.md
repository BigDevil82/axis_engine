# 业务概览

## 目标

将建筑平面图快速转换为可编辑的结构初步布置结果，帮助设计院工程师减少重复绘图和初始判断工作。

当前自动化范围分为两步：

1. 建筑骨架提取。
2. 基于骨架布置剪力墙和梁。

自动结果不是最终设计结果。系统必须允许工程师在每一步人工修正，并将修正后的结果重新传回业务后端做校准和后续计算。

## 参与角色

| 角色 | 责任 |
| --- | --- |
| 结构工程师 | 选择建筑图层、检查自动结果、人工修正、确认结构布置 |
| CAD 插件/UI | 读取图层图元、显示图形、提供编辑工具、写回 CAD |
| 业务后端 | 骨架提取、骨架校准、楼板闭合反馈、结构布置、结构校准 |

## 系统边界

### CAD 插件/UI 负责

- 读取当前 CAD 图形中的墙体、门窗、轴网图层基础图元。
- 将基础图元转换成业务接口约定的数据结构。
- 显示原始底图、骨架、楼板区域、剪力墙和梁。
- 支持增删改线段和属性。
- 将工程师修改后的骨架或结构结果回传业务接口。
- 将最终结果写回 CAD 图层。

### 业务后端负责

- 从墙体、门窗、轴网基础图元中提取骨架。
- 输出墙轴线、门窗嵌入线、轴网线和楼板分区。
- 对人工修改后的骨架做对齐、拓扑修复和剪枝。
- 基于确认后的骨架布置剪力墙和梁。
- 对人工修改后的结构结果做剪枝、延伸搭接和楼板分区重算。

## 核心业务对象

| 对象 | 说明 | 是否可编辑 |
| --- | --- | --- |
| 原始图元 | 墙、门窗、轴网图层的 `LINE/ARC/CIRCLE/POLYLINE` 等 | 由 CAD 控制 |
| 墙轴线 | 墙体单线表示，带墙厚 | 是 |
| 门窗嵌入线 | 位于墙轴线上的洞口线 | 是 |
| 楼板分区 | 骨架或结构线网围合出的闭合区域 | 主要用于检查 |
| 剪力墙 | 结构初步布置墙段 | 是 |
| 梁 | 边梁、阳台梁、连梁、板划分梁 | 是 |

## 产品形态建议

第一阶段更适合做 CAD 插件：

- 工程师无需离开 CAD 工作流。
- 图层读取、图元选择、结果写回都更自然。
- 后端业务算法可以独立部署，也可以先本地调用。

UI 不应只做“运行算法并画结果”，而应做成两段确认式工作流：

```text
建筑底图 -> 骨架结果 -> 工程师确认骨架 -> 结构结果 -> 工程师确认结构
```

## 成功标准

- 工程师能快速看出骨架是否闭合。
- 自动提取错误可以在图面上直接修正。
- 修正后不需要重新从原始 CAD 全量提取。
- 结构自动布置结果可继续人工调整，而不是只能接受或放弃。
- 最终剪力墙和梁可以回写 CAD。
