## 图面表现建议

### 骨架阶段

| 对象 | 建议表现 |
| --- | --- |
| 建筑底图 | 低对比灰色 |
| 墙轴线 | 红色或深色实线，线宽体现墙厚只在属性中显示 |
| 门窗嵌入线 | 青色或绿色 |
| 轴网 | 浅灰虚线 |
| 楼板分区 | 半透明浅色填充 |

### 结构阶段

| 对象 | 建议表现 |
| --- | --- |
| 剪力墙 | 红色粗线 |
| 外轮廓边梁 | 蓝色 |
| 阳台过梁 | 青色 |
| 连梁 | 橙色 |
| 板划分梁 | 紫色 |
| 楼板分区 | 半透明浅色填充 |

## 关键交互细节

- 图面对象应可点选，点选后高亮并显示属性。
- 线段编辑优先提供端点拖拽。
- 提交后端前应显示“当前结果已被人工修改”的状态。
- 楼板分区数量变化需要易于观察，便于判断闭合性。
